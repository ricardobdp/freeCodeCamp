# freeCodeCamp Proyectos & Certificaciones

Repositorio centralizado que contiene los proyectos y ejercicios prácticos desarrollados para completar las distintas certificaciones de [freeCodeCamp](https://www.freecodecamp.org/learn). 
Mi objetivo con este espacio es mantener un historial ordenado de mi aprendizaje técnico sin saturar mi perfil principal de GitHub.

---

## 📜 Certificaciones

Cada carpeta de este repositorio representa una certificación completada, organizada por tecnologías y herramientas:

### 🗄️ 1. Bases de Datos Relacionales
* **Enfoque:** Modelado de datos, consultas SQL avanzadas, PostgreSQL, Bash y control de versiones con Git.
* **Proyectos:**
  * [Universe Database](bases-de-datos-relacionales/universe-database/): Diseño y creación de una base de datos relacional desde cero utilizando PostgreSQL. Modelado de esquemas, definición de tipos de datos, llaves primarias y foráneas (`universe.sql`).
  * [World Cup Database](bases-de-datos-relacionales/worldcup-database/): Automatización de ingesta y análisis de datos. Desarrollo de scripts en Bash para leer un archivo CSV, poblar una base de datos y ejecutar consultas SQL complejas para extraer estadísticas (`worldcup.sql`, `insert_data.sh`, `queries.sh`).
  * [Salon Appointment Scheduler](bases-de-datos-relacionales/salon-appointment/): Programa interactivo desarrollado en Bash que se conecta a PostgreSQL para gestionar registros de clientes y citas, integrando lógica de programación con operaciones de bases de datos (`salon.sql`, `salon.sh`).
  * [Periodic Table Database](bases-de-datos-relacionales/periodic-table/): Refactorización, limpieza y corrección de integridad en una base de datos existente (ajuste de tipos de datos y restricciones). Incluye un script para consultar datos químicos y control de versiones (`periodic_table.sql`, `element.sh`).
  * [Number Guessing Game](bases-de-datos-relacionales/number-guessing-game/): Integración de Bash scripting con almacenamiento persistente en PostgreSQL para registrar el progreso y estadísticas de los usuarios. Proyecto versionado íntegramente con Git (`number_guess.sql`, `number_guess.sh`).
